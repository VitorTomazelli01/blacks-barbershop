# Black's Barbershop

Site da barbearia **Black's Barbershop**, em Sumaré (SP).

## Destaques

- Apresentação da barbearia, dos barbeiros e dos serviços com valores.
- **Agendamento online** integrado a uma planilha do Google (Google Apps Script).
- Contato direto pelo WhatsApp e localização no Google Maps.
- Layout pensado primeiro para o celular.

## Tecnologias

HTML, CSS e JavaScript puro · Google Apps Script como back-end do agendamento · Hospedado na Netlify.
